# src/data is seeding infrastructure, not a runtime data layer

`src/data/` contains TypeScript arrays of Pathfinder game data (feats, spells, traits, classes, etc.) that were compiled during the data-collection phase of the project. These arrays serve one purpose: populating Firestore via the seed scripts in `scripts/db/`. They are not the runtime data source and will be deleted once production seeding is complete. All runtime game data reads go through `GameDataService` → `FirestoreGameDataConnector` → Firestore. The `StaticGameDataConnector` imports `src/data/` for test isolation only; this is the single legitimate non-seeding use. A `README.md` at `src/data/` and header comments on each collection's `index.ts` reinforce this constraint at the point of access for automated agents and developers. The design decision is recorded here because the directory name and structure make it easy to misread as a runtime data layer — the constraint is architectural, not obvious from the code alone.
